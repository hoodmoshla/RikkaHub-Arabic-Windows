# 背景介绍
- 项目名称：Rikkahub Desktop
- 介绍：Rikkahub Desktop 是一个本地 AI Chatbot，现已更新到 1.4.1，它是一款原生 Windows 应用，同时支持 Linux 二进制编译部署和 Docker 部署
- 功能概述：支持用户自定义 LLM API 进行日常聊天对话，支持用户自定义配置搜索引擎、MCP、Skill、世界书、Lorebook 等等等等诸多功能，同时也支持用户上传图片和文件。篇幅有限，该项目有什么功能需要你自己探索，我只讲更改
- 项目开发背景：
  - Rikkahub Desktop 并非是我独立开发的应用，事实上，它的起源是一个叫做 Rikkahub 的安卓 APP(源码在 /Rikkahub-Android 下)，作者与我并非同一人，而 Rikkahub Desktop 是我重做的桌面端
  - 桌面端与 APP 端大部分功能相同，少部分功能为桌面端独有，还有些 APP 的功能我还没有完全对齐，因此二者会有些不同。
  - 为了方便两端用户将配置、会话等等使用数据进行互相迁移，我做了数据备份功能，使得PC→APP、APP→PC、PC→PC的备份迁移成为可能，但很遗憾原开发者并没有想要和我合作适配的想法，因此现在这些都是我单方面的行为。
- 项目运行现状：现在桌面端已经有了很多用户，他们往往也使用 APP 端
- 其他：
  - 该项目中还有一些无关的文件夹：/cherry-studio、/lobehub、/kelivo、/opencode-dev这些都是我在开发的时候拿来参考的其他项目，这些你现在都不用管，不用看；/tmp_doc 存储着我在该项目中进行工作的各种方案，属于草稿和过程文件
